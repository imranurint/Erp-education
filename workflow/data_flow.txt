PHASE 8: REPORTS
─────────────────
                  ┌────────────────────────────────────────────┐
                  │ All reports read from main_ledger:          │
                  │                                             │
                  │ Income Statement:                           │
                  │   Income:  SUM(credit) - SUM(debit)        │
                  │   Expense: SUM(debit) - SUM(credit)        │
                  │   Profit:  Income - Expense                │
                  │                                             │
                  │ Balance Sheet:                              │
                  │   Assets:      SUM(debit) - SUM(credit)    │
                  │   Liabilities: SUM(credit) - SUM(debit)    │
                  │   Equity:      SUM(credit) - SUM(debit)    │
                  │   Check: Assets = Liabilities + Equity     │
                  │                                             │
                  │ Trial Balance:                              │
                  │   All accounts: debit vs credit totals     │
                  │   Total DR must = Total CR                 │
                  │                                             │
                  │ Dashboard:                                  │
                  │   Aggregated from all domains               │
                  │   Students, payments, dues, commissions     │
                  └────────────────────────────────────────────┘
